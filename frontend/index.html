Technical Viva Highlights

  • Core Engine: Compiled C++ (MinGW-W64 GCC) using pure object-oriented design (Encapsulation, Composition, Dependency Injection).
  • REST Protocol: Single-header cpp-httplib running on Winsock2 with non-blocking endpoint routing.
  • Serialization: nlohmann/json parsing and emitting JSON strings with zero memory leaks.
  • Data Persistence: Atomic file I/O writing pipe-delimited records to medicines.txt.
  • Time Calculus: System clock normalization via POSIX <ctime> structure tm.
